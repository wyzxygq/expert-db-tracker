# 专家库动态追踪（零成本 · 个人版）

每天自动抓取你关注的省份公告 → 有更新推送到你的**微信**，同时生成一个**免费网页**随时查看。

- 💰 全部费用：**0 元**
- 🤖 每天北京时间 06:00 全自动运行
- 📱 网页可"添加到手机主屏幕"，像 App 一样打开

```
GitHub Actions 定时任务(每日 06:00)
    └─ 抓取公告页 → 关键词筛选 → 去重
         ├─ 有新增 → 推送到微信(PushPlus)
         └─ 更新 data.json → GitHub Pages 网页自动刷新
```

## 目录结构

```
expert-db-tracker/
├── .github/workflows/daily-update.yml   # 定时任务(每天06:00)
├── scripts/
│   ├── fetch.py        # 采集+筛选+去重+推送 主脚本
│   └── sources.json    # 数据源配置（改成你关注的省份公告页）
├── index.html          # 展示网页（GitHub Pages 用）
├── data.json           # 数据文件（脚本自动更新，网页读取它）
└── state.json          # 去重记录（脚本自动维护，可忽略）
```

## 快速上手（约 15 分钟）

### 第 1 步：新建 GitHub 仓库

1. 打开 https://github.com （没有账号就注册一个，免费）
2. 点右上角 **+** → **New repository**
3. 仓库名填 `expert-db-tracker`，**选择 Public**（免费网页必需），勾选 *Add a README*，点 **Create repository**
4. 把本文件夹里的内容上传：进入仓库 → **Add file → Upload files** → 把 `expert-db-tracker` 文件夹里的**所有文件**（含隐藏的 `.github` 文件夹）拖进去 → **Commit changes**

> 提示：`.github` 是隐藏文件夹，Windows 上需在文件管理器勾选"显示隐藏项目"，或用命令行上传。

### 第 2 步：获取微信推送 Token（PushPlus，免费）

1. 手机微信扫一扫登录 https://www.pushplus.plus
2. 进入 **一对一推送**，复制你的 **Token**（一串字符）
3. 回到 GitHub 仓库 → **Settings → Secrets and variables → Actions → New repository secret**
   - Name 填：`PUSHPLUS_TOKEN`
   - Secret 填：刚复制的 Token
   - 点 **Add secret**

> 推送效果：关注"pushplus 推送加"公众号后，每天有更新时你会在微信收到服务通知，点开即看详情。免费版每天额度足够（每天推 1 条）。

### 第 3 步：开启免费网页（GitHub Pages）

1. 仓库 → **Settings → Pages**
2. **Source** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)` → **Save**
3. 等 1~2 分钟后，网页地址为：
   `https://你的用户名.github.io/expert-db-tracker`
4. 手机浏览器打开该网址 → 右上角菜单 → **添加到主屏幕**，以后像 App 一样用

### 第 4 步：配置你关注的省份（关键）

**本仓库已内置湖北/武汉 3 个真实数据源**，无需配置即可直接使用：

| 数据源 | 网址 | 收录内容 |
|--------|------|----------|
| 湖北省综合评标评审专家库·通知公告 | `hbggzyfwpt.cn/zjTzgg` | 评标专家续聘、继续教育、劳务报酬、征集入库等省级动态 |
| 武汉市公共资源交易中心·通知公告 | `ggzyfw.wuhan.gov.cn` | 武汉市专家征集、咨询专家遴选、远程异地评标提示等 |
| 湖北省政府采购网·通知公告 | `ccgp-hubei.gov.cn` | 全省政府采购评审专家劳务报酬、征集通知等 |

如需**增加或调整**，编辑 `scripts/sources.json`，按同样格式追加一条即可：

```json
{
  "id": "hb-zfcg",
  "name": "湖北·某交易网公告",
  "province": "湖北",
  "url": "https://真实公告页网址",
  "keywords": ["专家库", "入库", "申报", "征集"]
}
```

- `province`：显示在网页和推送里的省份名
- `keywords`：标题包含其中任意词的公告才会被收录；留空 `[]` 表示全部收录
- 可以加多个省份，复制几段即可

**怎么找公告页网址？** 搜索"省份名 + 专家库/评标专家/公共资源交易中心/政府采购网"，找到**列表页**（能看到多条公告标题的页面），把网址填进去。

> 已内置对两类政府网站公告链接的解析：普通 `<a href>`（如湖北省专家库）和 `onclick="window.open(...)"`（如武汉市交易中心），新增源一般无需改代码。

### 第 5 步：测试（必做）

1. 仓库 → **Actions** → 左侧 **daily-update** → 右侧 **Run workflow** → 绿色按钮
2. 等约 30 秒，刷新页面看到绿色对勾即成功
3. 打开你的网页，应能看到数据；微信应收到测试推送（若配置了 Token）

### 第 6 步：以后完全自动

每天北京时间 06:00 自动运行一次：抓取 → 更新网页 → 有新增推送微信。**你什么都不用做。**

## 常见问题

| 问题 | 原因与解决 |
|------|-----------|
| Actions 显示红色失败 | 点进任务看日志；多数是公告页抓取失败（源网址变了/被反爬），脚本对单个源失败会跳过，不影响其他源 |
| Actions 运行但抓不到国内政府网站 | GitHub 服务器在海外，个别政府网站访问慢/超时属正常。已内置 30 秒超时与单源跳过；若某源持续失败，可在本地 `python scripts/fetch.py` 确认是否还能访问，并考虑删掉该源或换国内 CI |
| 微信没收到推送 | ① 未设置 `PUSHPLUS_TOKEN`；② 当天**没有新增**（脚本设计为"有新才推"，无新增不打扰）；③ Token 填错 |
| 想换推送时间 | 编辑 `.github/workflows/daily-update.yml` 里的 `cron: '0 22 * * *'`（UTC 时间，北京时间 = UTC+8） |
| 公告页是 JS 动态渲染抓不到 | 换"列表页"（服务端渲染的公告列表），或加一个静态列表源 |
| 网页打不开/不更新 | 确认仓库是 Public、Pages 部署分支为 main；每次 Actions 运行后约 1 分钟更新 |

## 进阶（可选）

- **通知去重**：脚本内置基于"标题+链接"的去重，重复公告不会重复推送
- **截止时间提醒**：公告正文解析可在 `fetch.py` 中扩展（提取 deadline 字段后，网页会自动显示倒计时）
- **换推送通道**：如改用 Server酱，仅需替换 `push_wechat` 函数中的 API
- **更多来源**：把来源扩展为 RSS 也支持（fetch.py 已兼容一般 `<a>` 列表解析）
